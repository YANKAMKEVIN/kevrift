KEVRIFT

Plonge dans la Faille. Traverse trois strates de cristal vivant, deviens plus fort à chaque salle et brise l'Archonte qui garde le fond.

Comment jouer

Clavier et souris

ZQSD / WASD / flèches : bouger

Souris : viser

Clic gauche / J : lame

Clic droit / K : rune

Espace / Maj : esquive

E : Nova

Échap : pause

Manette

Stick gauche : bouger

Stick droit : viser (sinon visée auto)

X / RT : lame

Y / LT : rune

A / RB : esquive

B / LB : Nova

Start : pause

Astuces

Ta lame renvoie les projectiles ennemis : frappe-les au bon moment.

L'esquive te rend intouchable un court instant.

Chaque coup charge la Nova : une onde qui balaie tout l'écran.

Après chaque salle, choisis une amélioration puis un portail.

Réglages

Secousses de l'écran Lueur intense

Choisis ton pouvoir

Pause

Tu es tombé

Tourne ton appareil à l'horizontale pour plonger dans la Faille.
